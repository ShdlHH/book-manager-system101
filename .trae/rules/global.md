前言（规范核心定位）
本规范为AI代码生成专属强制契约，优先级最高，所有AI编码必须严格遵循，禁止自由发挥、禁止新增自定义逻辑、禁止偏离格式与约束。核心目标：统一团队编码标准、彻底规避版本兼容/联调/权限/图标/请求高频bug、保证每一次AI生成代码可直接运行、可无缝联调、无冗余、无报错。
规则优先级：全局强制固定规则 > 前后端自定义配置 > 业务需求 > AI默认生成逻辑
一、全局固定通用规范（前后端统一、禁止任何修改、AI最高优先级遵守）
本章节所有规则为项目底层统一契约，前后端均不可修改、不可变通、AI禁止自定义适配，所有业务开发、代码生成必须严格适配本规则。
1. 全场景统一命名规则（零歧义强制约束）
- 前端变量/字段/请求参数/实体属性/方法：严格小驼峰（例：userName、orderId）
- 前端组件名/页面文件名：严格大驼峰（例：UserManage.vue、RoleList.vue）
- 数据库表名/字段名：严格下划线（例：user_info、create_time）
- 后端接口路径：小写+横线连接（例：/user/login、/role/list）
- Java类名：大驼峰，Mapper/Service/Controller分层命名统一后缀
2. RESTful 接口全局统一契约
- 请求方式固定：GET=查询、POST=新增、PUT=全量/局部更新、DELETE=删除
- 全局请求头默认：Content-Type: application/json
- 全局分页请求参数：pageNum（当前页码）、pageSize（每页条数），禁止自定义分页参数名
3. 全局固定响应体与状态码（结构永久不变）
   所有前后端接口返回结构强制统一，禁止新增、删除、修改字段：
   {
   "code": 200,
   "msg": "提示信息",
   "data": {}
   }
   全局固定状态码（禁止自定义新状态码）：
   200=操作成功、400=参数/业务校验失败、401=登录过期/未鉴权、403=权限不足、500=服务异常
4. 全局JWT统一鉴权规则（杜绝联调bug）
- 前端Token存储：localStorage，固定Key=token，禁止使用sessionStorage/cookie
- 请求头格式固定：Authorization: Bearer {token}（Bearer后必须带空格）
- 前端全局拦截器：自动携带Token、识别401强制跳转登录页、清空本地Token
- 后端鉴权：仅JWT，禁止Session、Cookie鉴权，全局拦截器统一校验
5. 全局通用数据处理统一规范
- 时间格式统一：前后端统一传输时间戳，前端页面展示格式化：YYYY-MM-DD HH:mm:ss
- 空值处理：后端返回null，前端统一渲染为空，禁止展示undefined、null文本
- 状态字段：所有状态统一数字枚举，禁止字符串状态（例：0=禁用、1=正常）
- 跨域规则：后端全局统一跨域配置，前端禁止单独配置跨域代理临时规则
6. AI编码通用禁区（全局生效、永久约束）
1. 禁止AI生成冗余代码、无效注释、测试代码、废弃变量
2. 禁止AI自定义工具类、自定义请求封装、自定义状态码、自定义命名
3. 禁止AI私自新增接口、新增字段、新增页面、新增权限
4. 所有注释仅保留核心业务逻辑，模板代码、基础逻辑禁止注释
7. 数据库全局固定规则
- 字符集统一：utf8mb4，存储引擎统一：InnoDB
- 全局通用字段：create_time、update_time，由数据库自动维护
- 字段映射规则：数据库下划线字段 → 代码小驼峰属性，AI自动映射、禁止错乱
